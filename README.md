
# HTML & CSS Resume

A clean, modern, and fully responsive professional resume template built using HTML5 and CSS3. Designed with readability and elegance in mind, this resume is easy to customize and perfectly optimized for both web viewing and printing/PDF export.

## Features

- **Semantic HTML5:** Structured with accessibility and clean markup in mind.
- **Modern CSS3:** Utilizes CSS Variables (Custom Properties) for easy theming, modern layouts, and professional typography.
- **Responsive Design:** Looks great on desktop, tablet, and mobile screens.
- **Print Friendly:** Includes dedicated print media styles to ensure clean PDF exports or direct printouts without unnecessary clutter.
- **Easy Customization:** Simply update the content directly in the HTML file and adjust colors/fonts in the CSS stylesheet.

## How to Run

No installation or dependencies are required. Open `index.html` directly in a web browser, or serve the project locally with any static web server.

Then visit `http://localhost:8000` in your browser.
